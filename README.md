# PDF Viewing Experience

This project is a web-based application that provides a seamless and interactive experience for viewing PDF documents. It's built with React, TypeScript, and Vite, offering a fast and modern development environment.

## Prerequisites

Before you begin, ensure you have the following installed on your system:

- [Node.js](https://nodejs.org/) (v18 or later)
- [pnpm](https://pnpm.io/)

## Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com/your-username/pdf-viewing-experience.git
   cd pdf-viewing-experience
   ```

2. **Install dependencies:**

   ```bash
   pnpm install
   ```

3. **Run the development server:**

   ```bash
   pnpm run dev
   ```

   The application will be available at `http://localhost:5173`.

## Available Scripts

- `pnpm run dev`: Starts the development server.
- `pnpm run build`: Builds the application for production.
- `pnpm run lint`: Lints the code using ESLint.
- `pnpm run check`: Runs ESLint and TypeScript checks.
- `pnpm run preview`: Starts a local server to preview the production build.
